# Bank Queue Management System

**Python | Data Structures & Algorithms | Flask | React**

Semester 3 Academic Project — FAST-NUCES

## Overview

This project was developed by a team of three students for our Data Structures and Algorithms course.

We created a simple bank queue management system to manage customer tickets, service priorities, and waiting queues. We first developed the basic logic in Python and later used AI assistance to help turn it into a web application with Flask and React.

## Features

- Customer login and registration
- Ticket generation and queue management
- Priority-based customer servicing
- Admin dashboard to manage queues
- Basic waiting-time calculations
- Simple banking operations
- Python backend connected to a React frontend

## How We Used AI

We initially made a simple Python program using the concepts we learned in our Data Structures and Algorithms course.

As the project became larger, we needed to connect the Python backend to the React frontend. Since we had not learned some of these technologies in class, our instructor encouraged us to use AI tools to help us learn and complete the project.

We used AI to understand new concepts, improve our existing code, connect different parts of the application, and fix errors.

The project was not created from a single AI prompt. We started with our own programming logic and used AI assistance during further development.
